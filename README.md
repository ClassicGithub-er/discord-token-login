# discord-token-login
There are 2 files in this repository, being the bookmarklet, and the script.
The bookmarklet works like any other (make a bookmark but put the code in the `link` section) and click it while on Discord's login page.
The script was the original script and it's intended to be pasted int he console of the discord login screen. (After filling in your token)

Feel free to use either, whether you want simplicity or legibility but you can rest assured these are bare minimum scripts that do NOT take any information (I will update this if I ever have a change of heart)
